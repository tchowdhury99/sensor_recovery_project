Final selected Phase 2 predictor:
V9 trained hybrid software sensor.

Formula:
x_hat[k+1] =
    w_naive * x_naive[k+1]
  + w_cv    * x_cv[k+1]
  + w_arx   * x_arx[k+1]

where:
x_naive[k+1] = x[k]
x_cv[k+1]    = 2*x[k] - x[k-1]
x_arx[k+1]   = x[k] + W*phi[k]

The weights are learned from validation data for each file and target.

Important conclusion:
The trained hybrid predictor is more stable than pure ARX and improves several dynamic cases.
